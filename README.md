# Dashboard
Dashboard criada como exemplo.
# Objetivo
Essa dashborad foi criada para auxiliar outras pessoas como podem criar uma dashboard, simples funcional e com um visual discreto.
# Base
Essa Dashboard foi gerada utilizando uma base de dados que está entre as planilhas ocultas, além disso existe uma planilha com assets utilizados e uma planilha de cálculos.
# Público
Qualquer pessoa que tenha interesse em criar uma Dashboard.
